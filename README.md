# Quantum Space Buddies 中文显示修复

本 Mod 用于解决《星际拓荒》（Outer Wilds）多人联机 Mod **Quantum Space Buddies（QSB）** 的中文文本无法正常显示的问题。

## 效果对比

| 安装本 Mod 前 | 安装本 Mod 后 |
| :---: | :---: |
| 中文文本无法正常显示 | 中文文本可以正常显示 |
| ![安装前：中文文本无法正常显示](docs/images/before-installing.png) | ![安装后：中文文本正常显示](docs/images/after-installing.png) |

## 说明

本 Mod 仅用于修复 Quantum Space Buddies 的中文显示问题，不包含 Quantum Space Buddies 本体。
